-----------------------------------------------------------
    Yablo's paradox in (the minimal-logic fragment of) Agda
  -----------------------------------------------------------

Agda is not "clever" enough to prove the paradox directly. But it can
prove two lemmas which togethers derive falsity.

The inhabited set X, its binary relation _<_ (called R in the minlog
development) and the predicate S are given as module parameters, for
the sake of simplicity.

\begin{code}

module Yablo (⊥ X   : Set)
             (c     : X)
             (_<_   : X → X → Set)
             (inf   : ∀ x → (∀ y → x < y → ⊥) → ⊥)
             (trans : ∀{x y z} → x < y → y < z → x < z)
             (S     : X → Set)
             (spec1 : ∀ x → S x → ∀ y → x < y → S y → ⊥)
             (spec2 : ∀ x → (∀ y → x < y → S y → ⊥) → S x)
 where

\end{code}

Agda's auto feature finds a proof that S(x) doesn't hold for all x.

\begin{code}

{- inferred by Agda's auto -}
Lemma : ∀ x → S x → ⊥
Lemma x s = inf x (λ y x<y → spec1 x s y x<y (spec2 y (λ z y<z → spec1 x s z (trans x<y y<z))))

\end{code}

It also proves S(c) where c is constant of X.

\begin{code}

{- can be inferred by Agda, with Lemma inlined -}
s : S c
s = spec2 c (λ y _ → Lemma y)

\end{code}

Agda doesn't search over the theorems that it has proved.  So let's
use the above proofs to derive ⊥ ourselves.

\begin{code}

bot : ⊥
bot = Lemma c s

\end{code}
